# Ahn-boat Lab 식구 갤러리

연구실 식구(박사·조수 하루·초파리 연구원·주판봇·인턴 시아·인턴 모아·X1~X3)와 MONEY-ROBO가 등장한 그림을 `github.com/adminmrobo`의 모든 공개 저장소에서 모아 보여 주는 갤러리입니다.

- 사이트: https://adminmrobo.github.io/ahnboat_lab_gallery/
- 그림마다 **원본 이미지**, **만든 프롬프트**(네거티브 포함), **실린 콘텐츠 이름**, **저장소 주소**, **생성일**, 같은 그림이 쓰인 다른 저장소를 보여 줍니다.
- **캐릭터 내비게이터**: 캐릭터를 눌러 거르고, 여러 명을 누르면 함께 나오는 그림을 찾습니다.
- **검색**: 캐릭터 이름(한국어·영어), 표정 이름(예: `하루 기쁨`), 콘텐츠 이름, 저장소, 파일 이름, 프롬프트 본문까지 찾습니다.
- 거르기: 종류(표지·장면·표정·포즈·모션·설정 시트·기타), 콘텐츠, 생성 월, 프롬프트 있는 것만. 주소(#)에 조건이 남아 그대로 공유할 수 있습니다.

> **MONEY-ROBO는 (주)M-Robo의 상표권이 있는 캐릭터로, 비상업적·상업적 이용이 모두 제한됩니다.**

## 데이터를 만드는 방법

| 항목 | 어디서 가져오나 |
|---|---|
| 그림 | 각 저장소의 png·jpg·webp·gif (같은 파일은 git 해시로 하나로 묶음) |
| 생성일 | 그 그림 파일이 저장소에 처음 올라간 커밋 날짜 |
| 프롬프트 | `specs/**.json`의 `prompt_en`·`negative_en`, `docs/` 그림 요청서(md)의 코드 블록·표 |
| 콘텐츠 이름 | `ahnboat_lab_cover_status/data/catalog.json` → `cover_manifest.json` → README 제목 순 |
| 캐릭터 | 파일 경로·명세의 `characters`/`who`·프롬프트의 캐릭터 묘사·요청서의 ‘등장:’ 줄 |

- 그림은 복사하지 않고 원래 저장소의 원본 주소를 가리킵니다. 목록 썸네일만 이미지 축소 서비스(wsrv.nl)로 줄여 보여 주고, 실패하면 원본을 씁니다.
- 시트에서 잘라 낸 컷(모션 프레임·헤어·작업복 등)은 시트를 만든 프롬프트를 보여 줍니다.
- 요청서에 영어 프롬프트 없이 장면 요지만 적힌 경우 ‘그림 지시문 (요약)’으로 표시합니다.
- 회사 저장소 `newsreporter_*`와 비공개 저장소는 넣지 않습니다.

## 갱신

```sh
sh scripts/collect.sh          # repos.txt의 저장소를 받아 data/gallery.json, data/prompts.json 다시 만들기
```

새 저장소를 만들면 `scripts/repos.txt`에 한 줄 추가합니다.
